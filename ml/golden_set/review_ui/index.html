골든셋 검수

templates 로 만든 검수표 CSV 를 넣고 화면에서 판정하면, 같은 스키마로 다시 내보냅니다. 파일은 브라우저 밖으로 나가지 않습니다.

1. 검수자

검수표를 넣으면 파일에 적힌 값을 그대로 읽어 옵니다. 판정 기록도 이 이름으로 따로 보관해서, 한 브라우저에서 A·B 패키지를 열어도 서로 섞이지 않습니다.

2. 검수표 CSV

필요한 표만 넣어도 됩니다. 넣은 표만 화면에 나옵니다.

3. 이미지 폴더

CSV 의 local_path(images/… 또는 E:\images\…)는 ZIP 을 푼 위치 기준이라 브라우저가 그대로 열지 못합니다. 그래서 파일 이름만 떼어 이 폴더에서 찾습니다. 폴더를 안 넣으면 이미지 없이 판정합니다.
