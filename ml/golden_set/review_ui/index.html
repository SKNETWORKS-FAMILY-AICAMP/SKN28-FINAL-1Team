골든셋 검수

templates 로 만든 검수표 CSV 를 넣고 화면에서 판정하면, 같은 스키마로 다시 내보냅니다. 파일은 브라우저 밖으로 나가지 않습니다.

1. 검수자

가이드는 reviewer-a / reviewer-b 로 통일하도록 돼 있습니다. 검수자 간 일치도를 이 열로 집계한다면 사람 이름 대신 이 값을 씁니다.

2. 검수표 CSV

필요한 표만 넣어도 됩니다. 넣은 표만 화면에 나옵니다.

3. 이미지 폴더

CSV 의 local_path 는 E:\images\… 같은 다른 PC 경로라 그대로 못 엽니다. 그래서 파일 이름만 떼어 이 폴더에서 찾습니다. 폴더를 안 넣으면 이미지 없이 판정합니다.
