# 레이어드 룩 (Layered Look) — 색상 규칙

> **60-30-10 법칙 + 5대 재킷 매칭표 + 3단계 레이어드 조합**
> 가을·겨울 시즌 필수 룩. 아우터+이너 2~3겹의 색 비율과 톤 매칭이 핵심.

---

## 1. 60-30-10 법칙 (체감온도 + 시각 균형)

레이어드는 단순히 여러 겹 입는 게 아니라 **시각적 면적 비율**에 따라 색을 배분한다.

```
바깥 (바람막이·보온) 60%  → 메인 컬러 (재킷·코트)
중간 (미세 보온·실내 단품) 30% → 보조 컬러 (니트·후디·가디건)
안쪽 (흡습·청결) 10% → 포인트 컬러 (셔츠·롱슬리브·티)
```

**왜 60-30-10인가**:
- 50-50은 양쪽 다 메인처럼 보여 시선 분산
- 70-20-10은 안쪽 포인트가 묻힘
- 60-30-10이 가장 안정적 시각 균형

---

## 2. 3단계 레이어드 조합

### 2.1. 1단계 — 무채색 이너 + 무채색 아우터 (가장 안전)

```
흰 티 / 그레이 맨투맨 + 블랙 재킷 + 차콜 코트
화이트 셔츠 + 그레이 니트 + 블랙 트렌치
```

**적합**: 출근, 면접, 미팅 (TPO: business/formal)
**카테고리**: NEUTRAL only
**장점**: 절대 실패하지 않음, 모든 시즌 OK
**단점**: 단조로움 → 포인트 액세서리(스카프, 시계, 가방)로 해결

### 2.2. 2단계 — 컬러 이너 + 무채색 아우터 (가장 흔함)

```
버건디 니트 + 차콜 재킷 + 블랙 코트
카키 셔츠 + 네이비 재킷 + 그레이 코트
올리브 맨투맨 + 베이지 트렌치 + 차콜 코트
```

**적합**: 일상, 캐주얼, 데이트 (TPO: casual/business-casual)
**카테고리**: WARM/COOL 1개 + NEUTRAL 2개
**장점**: 포인트 컬러가 살아남, 무채색이 안전판
**단점**: 이너 색이 30% 정도여야 함 (그 이상이면 안쪽이 메인처럼 보임)

### 2.3. 3단계 — 컬러 이너 + 컬러 아우터 (전문가용)

```
마룬 셔츠 + 카키 재킷 + 브라운 코트 (모두 earth tone)
코랄 니트 + 버건디 재킷 + 베이지 코트 (봄웜 anchor)
로열블루 티 + 차콜 재킷 + 네이비 코트 (겨울쿨 deep)
```

**적합**: 패션 의식 있는 일상, 촬영, SNS
**카테고리**: WARM 2개 + NEUTRAL 1개 (또는 COOL 2개 + NEUTRAL 1개)
**장점**: 톤온톤 또는 보색 대비로 세련된 인상
**단점**: 룰 L1~L5 (3색 이하, 뉴트럴 1+) 엄격히 적용 필요

## 3. 5대 재킷 매칭표 (실전 데이터)

| 재킷 종류 | 안에 입기 (중간 30%) | 팬츠 | 신발 | 베스트 상황 |
|----------|---------------------|------|------|------------|
| **네이비 블레이저** | 그레이 니트 / 화이트 셔츠 | 차콜 슬랙스 | 로퍼/더비 | 오피스, 프레젠테이션 |
| **필드/사파리 (Olive/Khaki)** | 후디 / 헤비티 | 인디고 데님 | 스니커즈 | 캐주얼 약속, 카페 |
| **베이지 트렌치** | 스트라이프 티 / 가디건 | 치노 (베이지) | 첼시/더비 | 데이트, 공연 |
| **차콜/블랙 재킷** | 플리스 베스트 / 버건디 니트 | 카고/테이퍼드 | 고어텍스 스니커즈 | 비/바람, 출퇴근 |
| **코듀로이/셔켓 (Brown)** | 니트 베스트 / 옥스포드 셔츠 | 다크 데님 | 월러비/로퍼 | 캠퍼스, 출근 캐주얼 |

### 3.1. 색 조합 치트시트

| 재킷 | 안감 (30%) | 바지 (60%) |
|------|-----------|-----------|
| **네이비 재킷** | 그레이/아이보리 | 차콜/베이지 |
| **올리브 재킷** | 오트/라이트그레이 | 인디고/브라운 |
| **베이지 트렌치** | 스트라이프/화이트 | 스톤/다크그레이 |
| **차콜 재킷** | 블랙/버건디 | 미디엄그레이 |
| **브라운/헤링본** | 크림/네이비 | 블랙/에크루 |

## 4. 시즌별 레이어드 추천

### 4.1. 봄웜 (Spring Warm)
- **아우터**: Beige 트렌치, Camel 코트, Light Olive 자켓
- **이너 (30%)**: Ivory 셔츠, Coral 니트, Peach 맨투맨
- **바지 (60%)**: Cream 슬랙스, Light Denim, Beige 치노
- **포인트 (10%)**: Brown 벨트, Coral 머플러

### 4.2. 여름쿨 (Summer Cool)
- **아우터**: Light Gray 자켓, Sage 카디건, Soft Beige 트렌치
- **이너 (30%)**: White 셔츠, Soft Rose 티, Lavender 맨투맨
- **바지 (60%)**: Light Denim, Stone 슬랙스, Medium Gray
- **포인트 (10%)**: Dusty Rose 머플러, Silver 액세서리

### 4.3. 가을웜 (Autumn Warm)
- **아우터**: Camel 코트, Brown 재킷, Olive 필드자켓
- **이너 (30%)**: Mustard 니트, Burnt Orange 셔츠, Terracotta 맨투맨
- **바지 (60%)**: Brown 코듀로이, Khaki, Dark Denim
- **포인트 (10%)**: Burgundy 머플러, Brown 가죽 벨트

### 4.4. 겨울쿨 (Winter Cool)
- **아우터**: Charcoal 코트, Black 다운, Navy 블레이저
- **이너 (30%)**: White 셔츠, Fuchsia 니트, True Red 맨투맨
- **바지 (60%)**: Black 슬랙스, Dark Denim, Charcoal
- **포인트 (10%)**: Royal Blue 머플러, Black 가죽

## 5. 레이어드 × 4 카테고리 룰

### R1. 한 아우터는 1 카테고리 안에서 해결
- WARM 재킷 (Camel, Olive, Brown) → WARM 이너 (Coral, Terracotta, Mustard)
- COOL 재킷 (Navy, Charcoal, Black) → COOL 이너 (Royal Blue, Cobalt, Fuchsia)
- NEUTRAL 재킷 (Beige, Gray) → 어느 카테고리든 OK

### R2. 3-tier 색상카피 (Tier Copying)
- 같은 색을 2개 tier에서 반복하면 통일감 ↑
- 예: Navy 재킷 + Navy 스카프 + Black 팬츠 = Navy가 2개 tier에 등장
- 단, 한 색이 3개 tier 모두면 단조로움

### R3. 명도 그라데이션 (Tier Lightness)
- 바깥 → 중간 → 안쪽: L값이 점진적으로 가거나 점진적으로 짙어짐
- 명도 점프 (L=20 → L=90)는 갑작스러움 → 점진적 (L=20 → L=50 → L=80)

### R4. 패턴 위치
- 패턴은 1개 tier에만, 나머지 2개는 솔리드
- 패턴 tier는 보통 30% (이너) 또는 10% (포인트) 권장
- 60% (재킷)에 패턴 = 너무 강함

---

## 6. 자주 하는 실수

| 실수 | 결과 | 해결 |
|------|------|------|
| 아우터 60%가 라이트 (Beige 트렌치)인데 안쪽도 라이트 (White + Beige) | 전체적으로 칙칙 | 안쪽에 한 가지 dark (Brown, Navy) 추가 |
| WARM 재킷 + COOL 이너 + NEUTRAL 팬츠 = 3 카테고리 | 시각 혼잡 | 카테고리 2개로 통일 |
| 이너가 아우터 밖으로 많이 나옴 (긴 티) | 비율 무너짐 | 이너 기장은 아우터보다 살짝만 길게 |
| 머플러/스카프가 아우터 색과 완전 동일 | 통합감 0 (구분 안 됨) | 같은 카테고리 안에서 한 단계 명도 차이 |
| 고채도 (Coral, Fuchsia) 2개 tier 동시 사용 | 과함 | 1개 tier만 accent, 나머지는 톤다운 |

## 7. 활용 시나리오

### 7.1. 추구미 (PursuitMe)
- "60-30-10 비율 슬라이더" + "재킷 종류" 필터로 5대 매칭표 직접 선택
- 시즌 anchor 자동 적용 (봄웜 → Beige/Coral 우선)

### 7.2. 채팅 에이전트
```
사용자: "내일 비 오는데 가을웜이야. 뭐 입지?"
에이전트:
  추천: "Camel 트렌치 (60%) + Burnt Orange 니트 (30%) + White 셔츠 (10%) + Brown 슬랙스"
  이유:
    - 60-30-10 비율로 안정적 시각 균형
    - 가을웜 anchor: Camel/Brown + Burnt Orange
    - 레이어드 룰 R3 (명도 그라데이션): L(트렌치)=70, L(니트)=50, L(셔츠)=100
```

### 7.3. 옷장 RAG
- wardrobe_item에 `tier` (outer/middle/inner) 필드 추가
- 같은 카테고리 내 60-30-10 비율 매칭 → outfit 자동 생성
