# 패턴 / 무늬 매칭 (Pattern Mixing)

> **9가지 런웨이 룰 + 4가지 조합 예시 + 멀티 보조색 처리**
> 스트라이프 · 체크 · 플로럴 · 도트 · 그래픽 · 애니멀 패턴의 매칭 규칙

---

## 1. 왜 패턴 매칭이 어려운가

패턴이 들어간 옷은 **2개 이상의 색**을 동시에 가지고 있어서 단순 2색 룰(R1~R6)로 판정할 수 없다.

예) 네이비 바탕 + 화이트 스트라이프 셔츠:
- `color`: Navy
- `secondary_color`: White
- `pattern_type`: stripe

→ **메인 색만으로 룰 적용하면 정보 손실**. 패턴은 2~3색이 한 아이템에 공존하므로 `secondary_color` 필드 + `pattern_type` 필드 추가 필요.

---

## 2. 9가지 패턴 매칭 룰

### R-P1. 큰 패턴 + 작은 패턴 (가장 기본)
- 큰 패턴(체크 코트) + 작은 패턴(핀스트라이프 셔츠) ✓
- 비슷한 크기 패턴 두 개(미디엄 체크 + 미디엄 스트라이프) ✗
- 근거: 시각 위계 (한 패턴이 dominant, 다른 하나는 texture)

### R-P2. 톤 비슷하게 맞추기
- 두 패턴의 **전체 색조(cool/warm/neutral)**를 같게
- 예: 따뜻한 톤 체크 + 따뜻한 톤 플로럴 ✓
- 차가운 톤 스트라이프 + 따뜻한 톤 도트 ✗
- 근거: 톤이 다르면 패턴이 충돌

### R-P3. 같은 계열 컬러
- 패턴 안에 **공통으로 들어간 색 1개**를 기준으로 매칭
- 예: 체크 안에 Navy + Brown + Cream → Cream이 다른 패턴에도 있으면 OK
- 근거: 공통 색 = 시각적 연결점

### R-P4. Black/Neutral과 믹스
- 어떤 패턴이든 **Black 또는 White**와 매치하면 안전
- 호피 코트 + Black 슬랙스 ✓
- 플로럴 블라우스 + White 팬츠 ✓
- 근거: 무채색이 패턴의 chaos를 정리

### R-P5. 무지 1개 + 패턴 1개로 시작
- 처음에는 무지 2개 + 패턴 1개 (가장 안전)
- 자신감 붙으면 무지 1 + 패턴 2
- 무지 0 + 패턴 3 = 추후 도전
- 근거: 무지가 시각적 휴식

### R-P6. 패턴끼리 거리 두기
- 패턴 팬츠 + 나머지 모노톤
- 패턴 스카프/액세서리로 포인트
- 근거: 한 곳에 패턴 집중 = 시선 분산 방지

### R-P7. 세 요소 중 하나는 비우기
- 정장 패턴 매치: 재킷/셔츠/타이 3개 중 1개는 무지
- 예: 무지 재킷 + 무지 셔츠 + 패턴 타이 (안전)
- 패턴 재킷 + 무지 셔츠 + 무지 타이 (한 단계 위)
- 큰 패턴 + 잔잔한 패턴 + 무지 (숙련자)
- 근거: 한 요소가 비어야 시각 호흡

### R-P8. 비슷한 크기 패턴 두 개 피하기
- 미디엄 체크 + 미디엄 스트라이프 = 둘 다 "dominant" → 충돌
- 한 단계 크게 또는 작게 차이 나게
- 근거: 패턴 위계

### R-P9. 공통 색 추출 (Color Anchor)
- 두 패턴에서 **공통으로 등장하는 색 1개**를 anchor로 매칭
- 플로럴 안에 Navy + Pink + Yellow → Navy를 anchor로 다른 패턴과 매칭
- 근거: 한 색이 두 패턴을 시각적으로 연결

## 3. 4가지 조합 예시

### 3.1. 스트라이프 + 체크 (가장 쉬움)
```
상의: Black & White 스트라이프 셔츠
하의: Brown 체크 팬츠
신발: Black 로퍼
```
- R-P1: 스트라이프(중간) + 체크(중간) → 약간 비슷 → R-P8 위험
- 해결: 셔츠 핀스트라이프(가는) + 체크(굵은) → 크기 차이 확보
- R-P3: 공통 색 Black/Brown 둘 다 dark → OK

### 3.2. 밀리터리 + 플로럴
```
상의: Olive 밀리터리 카고 (패턴 X, 단색)
하의: 플로럴 스커트 (Pink + Green + White)
신발: White 스니커즈
```
- R-P6: 패턴 1개 (스커트) + 나머지 모노톤
- R-P4: White 스니커즈가 패턴 chaos 정리
- R-P3: 공통 색 Green/Olive (카고 + 플로럴)

### 3.3. 도트 + 플로럴
```
상의: Navy 도트 블라우스 (작은 도트)
하의: Ivory 플로럴 스커트 (큰 꽃무늬)
신발: Nude 플랫
```
- R-P1: 도트(작음) + 플로럴(큼) → OK
- R-P3: 공통 색 Navy/Ivory 둘 다 neutral
- R-P2: 둘 다 cool/neutral 톤

### 3.4. 그래픽 + 애니멀 (도전)
```
상의: 그래픽 티셔츠 (다색)
하의: Leopard 스커트 또는 Leoprint 팬츠
신발: Black 부츠
```
- R-P5: 무지 0 + 패턴 2 = 도전
- R-P7: 신발(Boot)을 무지로 → 3요소 중 1 무지
- R-P9: 그래픽의 Black + Leoprint의 Black anchor

## 4. 패턴별 특성표

| 패턴 | 메인 컬러 | 보조 컬러 | 추천 카테고리 | 추천 매치 |
|------|----------|----------|--------------|----------|
| **스트라이프 (세로)** | 다양 | 보통 1-2 | NEUTRAL 베이스 | 다른 패턴 OK |
| **스트라이프 (가로)** | 다양 | 1-2 | NEUTRAL | 가로 = 가로 분할 효과 주의 |
| **체크** | 다양 | 2-3 | 다양 | 톤온톤 or Black/White |
| **플로럴 (작은)** | 다양 | 다색 | 봄웜/여름쿨 | 단색과 매치 |
| **플로럴 (큰)** | 다양 | 다색 | 여름쿨 | 단색 또는 작은 패턴 |
| **도트 (작은)** | 다양 | 1-2 | 다양 | 다른 패턴 OK |
| **도트 (큰/폴카)** | 다양 | 1 | 다양 | 단색과 매치 |
| **그래픽/타이포** | 다양 | 다색 | Cool accent | Black/White와 |
| **애니멀 (호피)** | Brown/Black | Black | WARM/MUTED | Black/White/Nude |
| **애니멀 (지브라)** | Black/White | White | NEUTRAL | Black/White |
| **밀리터리/카무플라쥬** | Olive/Khaki | Brown | MUTED | 단색 |

## 5. 멀티 보조색 처리 (Multi-Color Items)

### 5.1. 1차 전략: `secondary_color` 필드 추가
- 메인 색: 1개
- 보조 색: 1~2개 (선택)
- 예: Navy 바탕 + White 스트라이프 → main=Navy, secondary=White

### 5.2. 2차 전략: `pattern_type` 필드
- `solid` (단색, 기본)
- `stripe_vertical` / `stripe_horizontal`
- `check_small` / `check_medium` / `check_large`
- `floral_small` / `floral_large`
- `dot_small` / `dot_large`
- `graphic` (그래픽/타이포)
- `animal_leopard` / `animal_zebra` / `animal_snake`
- `military` (카무플라쥬)
- `multi` (3색 이상 복잡 패턴)

### 5.3. 룰 적용
- 패턴 아이템 2개 이상 매치 시: R-P1~R9 적용
- 패턴 1개 + 솔리드 1개: 기본 R1~R6 + R-P4
- 패턴 1개 + 솔리드 2개: L1 (3색 룰) 자동 통과

## 6. 정장 패턴 매치 (Doverman 룰)

정장은 3요소 (재킷, 셔츠, 타이) 패턴 매치:

| 상황 | 재킷 | 셔츠 | 타이 |
|------|------|------|------|
| **가장 안전** | 무지 | 무지 | 패턴 1 |
| **한 단계 위** | 패턴 | 무지 | 무지 또는 솔리드 |
| **숙련 단계** | 큰 패턴 | 잔잔한 패턴 | 무지 |
| **피해야 할 예** | 중간 패턴 | 중간 패턴 | 중간 패턴 |

**추가 규칙**:
- 패턴마다 색이 다르면 무늬 안에 **공통 색 1개**를 anchor
- 한 요소는 비워서 여백 만들기 (R-P7)

## 7. 활용 시나리오

### 7.1. 추구미
- "패턴 매칭" 필터 추가 (스트라이프만 / 체크만 / 매칭 OK)
- 패턴별 추천 카테고리 자동 분류

### 7.2. 채팅 에이전트
```
사용자: "체크 팬츠 샀는데 뭐랑 입지?"
에이전트:
  추천: "White 셔츠 + Brown 코듀로이 자켓 + Black 로퍼"
  이유:
    - R-P6 (패턴 팬츠 → 나머지 모노톤)
    - R-P4 (White가 패턴 chaos 정리)
    - R-P3 (Brown = 체크 안의 공통 색)
```

### 7.3. 옷장 RAG
- 색상 추출 시 main + secondary 분리
- `pattern_type` 자동 분류 (ML 모델 또는 rule-based)
- R-P 룰 자동 적용
