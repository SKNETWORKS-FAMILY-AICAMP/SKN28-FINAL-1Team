## 3. 드레스/치마 룩 매칭 룰

### 3.1. 단독 (One-piece Dress) — 1색 룩
- 1색 드레스는 **3가지 옵션**:
  1. **뉴트럴 + 액세서리 컬러풀** (Black 드레스 + Red 슈즈/가방)
  2. **컬러풀 + 뉴트럴 액세서리** (Red 드레스 + Nude 슈즈)
  3. **모노톤 멀티** (Burgundy 드레스 + Burgundy 가방 + Nude 슈즈)

### 3.2. 원피스 + 아우터 (레이어드)
- 기본 60-30-10 법칙 적용 (06-layered-look.md 참조)
- **드레스 = 60% (가장 큰 면적)** → 메인 컬러
- 아우터 (재킷/카디건) = 30%
- 신발/가방 = 10%

### 3.3. 치마 + 상의
- 기존 17 tops × 12 pants 매트릭스에서 **치마 = pants 자리**에 대입
- 즉, 17 tops × 12 skirts (치마 팔레트) = 204 조합
- 치마 색상은 pants 팔레트와 동일 (Denim, Beige, Black, Brown, Khaki 등)

### 3.4. 셔츠 원피스 (Shirt Dress) — 2색 룩
- 단색 셔츠 + Belt (같은 색 or 1단계 darker)
- 또는 셔츠 1개 + 다른 색 Belt + 다른 색 슈즈

## 6. 활용 시나리오

### 6.1. 추구미
- 카테고리 필터: 상의 / 하의 / **드레스 / 치마 / 아우터**
- 드레스/치마 선택 시 확장 21색 팔레트 노출
- 원피스 단독 룩 vs 레이어드 룩 토글

### 6.2. 채팅 에이전트
```
사용자: "여름에 입을 화사한 원피스 추천"
에이전트:
  추천: "Pistachio 미디 원피스 + Cream 가디건 + Sandal"
  이유:
    - 21색 중 Pistachio (봄웜 anchor, 2024 +90%)
    - Cream 가디건 (NEUTRAL 베이스, L1~L5 통과)
    - Icy Blue 액세서리 옵션 (MUTED 추가, Color Anchor R-P3)
```

### 6.3. 옷장 RAG
- `wardrobe_item.category`에 `dress` / `skirt` 추가
- 색상 추출 + 패턴 매칭 동일 파이프라인
- 21색 centroid로 매칭
