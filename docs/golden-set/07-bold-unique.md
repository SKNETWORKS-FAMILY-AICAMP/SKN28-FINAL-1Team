# 독특한 / 화려한 색상 (Bold & Unique)

> **무난한 베스트셀러 외 — Color Clash, Bold Leopard, Sage/Olive, 네온**
> 2024 F/W 런웨이 트렌드 + 확장 팔레트. 일반 사용자도 취향 표현용으로 활용 가능.

---

## 1. 왜 별도 섹션인가

대부분의 색상 가이드는 "안전한 조합" 위주다. 하지만:

- **일부 사용자는 네온/호피/시퀸 같은 화려한 색을 선호** — "튀는 게 좋다"
- **K-pop, 스트릿, 애슬레저 등 특정 장르**는 본질적으로 high-chroma
- **이들 색상은 기본 17색 팔레트에 없음** → 별도 확장 필요

이 섹션은 **17색 외 5가지 bold 카테고리**를 정의하고, **언제 어떤 룰로 통합할지** 정리한다.

## 2. 2024 F/W 4대 트렌드

### 2.1. Color Clash (네온 + 파스텔 + 보색 대비)
- **출처**: Harpers Bazaar 2024 F/W — "실험적 꽃무늬, 네온, 파스텔, 보색 대비"
- **대표 매치**:
  - 네온 옐로 + 스카이블루
  - 핫 핑크 + 바이올렛
  - 네온 오렌지 + 라임
- **카테고리 매핑**: 모두 ACCENT (chroma ≥45) — R3 룰 위험
- **안전장치**: 룩 룰 L3 (고채도 1개까지) + 뉴트럴 완충 필수
- **추천 룩**: "옐로 니트 + 라임 스커트 + Black 액세서리" (뉴트럴 1개로 분리)

### 2.2. Bold Leopard (호피 패턴)
- **출처**: 2024 F/W 런웨이 — "맥시멀리즘의 부활, 미니멀리즘의 반란"
- **추천 매치**:
  - 호피 코트 + Black 슬랙스 (가장 흔함)
  - 호피 니트 + Denim 팬츠
  - 호피 원피스 + Boots
- **카테고리 매핑**: WARM accent (Brown + Black 패턴)
- **주의**: 패턴이라 `secondary_color`로 Brown/Black 2색 추출됨
- **룰**: 무지 아이템과 1:1 매치 (패턴끼리 매치 금지)

### 2.3. Sage Green (차분한 자연)
- **출처**: InStyle 2024 F/W — "차분한 Sage Green, Boho-chic"
- **Hex**: #9CAF88
- **카테고리 매핑**: MUTED (저채도 green)
- **추천 매치**:
  - Sage 가디건 + Cream 셔츠 + Brown 팬츠
  - Sage 코트 + White 티 + Black 슬랙스
- **시즌 anchor**: 여름쿨 (soft summer)
- **차별점**: 일반 Olive (#6B6B45)보다 훨씬 부드럽고 채도 낮음

### 2.4. Olive Green (고급 자연)
- **출처**: L'OFFICIEL 2024 F/W — "고급스러운 Olive Green, 더블 레이어링"
- **Hex**: #6B6B45 (이미 17색 팔레트에 있음)
- **카테고리 매핑**: WARM semi_neutral
- **추천 매치**:
  - Olive 코트 + Cream 셔츠 + Black 팬츠
  - Olive 재킷 + Brown 니트 + Beige 팬츠
- **시즌 anchor**: 가을웜
- **차별점**: Sage보다 짙고 채도 높음 → 가을·겨울 중심

## 3. 네온 (Neon) 카테고리

3가지 네온 + 활용 가이드.

### 3.1. Hot Pink
- **Hex**: #FF69B4
- **온도**: Warm
- **Chroma**: 매우 높음 (~70)
- **추천 매치**:
  - Hot Pink 액세서리 (가방, 신발) + 올블랙
  - Hot Pink 니트 + Gray 슬랙스
  - Hot Pink 코트 + Black inner (60-30-10의 10% 포인트)
- **룰**: chroma ≥70 → L3 (고채도 1개까지) 엄격 적용
- **시즌 anchor**: 겨울쿨 (Bright Winter)

### 3.2. Neon Yellow
- **Hex**: #DFFF00
- **온도**: Warm
- **Chroma**: 매우 높음 (~85)
- **추천 매치**:
  - Neon Yellow 포인트 (모자, 가방) + Olive/Beige 기본
  - Neon Yellow 맨투맨 + Black 팬츠
  - 신발/스포츠웨어에서만
- **룰**: 면적 최소화 (전체 10% 미만)
- **시즌 anchor**: 봄웜 (Bright Spring) — 단, 모든 시즌 포인트 OK

### 3.3. Electric Blue
- **Hex**: #7DF9FF
- **온도**: Cool
- **Chroma**: 매우 높음 (~60)
- **추천 매치**:
  - Electric Blue 액세서리 + White/Beige 기본
  - Electric Blue 운동화 + 올블랙
- **시즌 anchor**: 겨울쿨

## 4. 확장 팔레트 (17색 + 5 bold)

| 이름 | hex | 카테고리 | chroma | 시즌 anchor |
|------|-----|---------|--------|------------|
| Hot Pink | #FF69B4 | ACCENT (WARM) | 70 | 겨울쿨 |
| Neon Yellow | #DFFF00 | ACCENT (WARM) | 85 | 봄웜 |
| Electric Blue | #7DF9FF | ACCENT (COOL) | 60 | 겨울쿨 |
| Sage Green | #9CAF88 | MUTED (COOL) | 25 | 여름쿨 |
| **17색 팔레트** | (기존) | — | — | — |
| **+ Leoprint** | (Brown+Black) | PATTERN | — | 가을웜 |
| **+ Floral** | (다색) | PATTERN | — | 봄웜/여름쿨 |

**통합 방법**:
- `wardrobe_item.color`에 17색 외 bold 5개도 추가 (총 22색)
- 또는 `secondary_color`로 분리 (Leopard: Brown + Black, Floral: main + accent 2~3)

## 5. 화려한 룩 룰 (L1~L5 + 화려한 확장)

기존 룩 룰에 추가:

| # | 규칙 | 근거 |
|---|------|------|
| **L6** | 네온/시퀸/글리터는 **10% 미만**으로 | 60-30-10 법칙의 10% tier만 |
| **L7** | Bold 패턴 (호피/지브라) 1개 + 솔리드 2개 | 패턴끼리 충돌 방지 |
| **L8** | Color Clash 시 뉴트럴 1개 + clash 2개 = 3색 (L1 한도) | L1 유지하면서 시각 임팩트 |
| **L9** | Sage/Olive/Muted는 WARM·COOL 양쪽 다 OK | 카테고리 경계가 모호 |
| **L10** | High-chroma (≥70)는 액세서리/포인트만 | chroma 과다 노출 방지 |

## 6. 4 카테고리 + Bold 통합 매트릭스

| 카테고리 | 메인컬러 | Bold 확장 | 추천 매치 |
|---------|---------|----------|----------|
| **WARM** | Coral, Mustard, Terracotta, Rust | + Hot Pink, Neon Yellow | Black / Cream / Brown |
| **COOL** | Royal Blue, Cobalt, Fuchsia, Teal | + Electric Blue | White / Beige / Sage |
| **NEUTRAL** | Black, White, Charcoal, Navy, Beige, Gray | + Olive, Sage | (모든 컬러와 매치) |
| **MUTED** | Dusty Rose, Mauve, Sage, Taupe, Stone | + Sage Green | Cream / Ivory / Brown |

## 7. 활용 시나리오

### 7.1. 추구미 "Bold Mode"
- 일반 모드 (17색 only) vs Bold 모드 (22색) 토글
- Bold 모드에서만 네온/호피/Sage 추천 노출
- 사용자가 "화려한 거 좋아해요" 선택 시 자동 활성화

### 7.2. 채팅 에이전트
```
사용자: "튀는 색 좋아해. 봄웜이야"
에이전트:
  추천 모드: Bold
  추천: "Coral 니트 + Beige 슬랙스 + Neon Yellow 머플러 (10% 포인트)"
  이유:
    - 봄웜 anchor (Coral/Beige) + L6 (Neon 10% 미만)
    - 룩 룰 L8: 3색 (WARM 1 + NEUTRAL 1 + ACCENT 1)
```

### 7.3. 옷장 RAG
- 색상 추출 시 22색 centroid에 매칭
- Leopard/Floral 같은 패턴은 main + secondary 2~3색으로 분리 저장
- `pattern_type` 필드 추가 (`solid` / `leopard` / `floral` / `stripe` / `check` / `dot` / `graphic`)

---

## 8. 안전장치

- **L10 엄격 적용**: chroma ≥70은 면적 10% 이하
- **사용자 취향 우선**: `style_preferences.bold_level` (0=safe, 1=balanced, 2=bold)
- **TPO 게이트**: 면접/장례식에서는 Bold 자동 OFF
- **시즌 anchor 약화**: Bold 색상은 시즌 anchor 약하게 적용 (모든 시즌 OK)
